# Codex Rules For This MVP

## Scope discipline

- Implement one MVP phase at a time.
- Do not skip ahead to future phases.
- Keep Phase 0 focused on structure, starter preservation, and documentation.

## Phase 0 exclusions

- Do not add LiveKit token generation yet.
- Do not add restaurant ordering logic yet.
- Do not add a database, analytics, admin dashboard, telephony, or production deployment.

## Starter preservation

- Keep `apps/web` aligned with the official LiveKit React starter as much as possible.
- Keep `apps/agent-runtime` aligned with the official LiveKit Python starter as much as possible.
- Any early changes should be minimal and clearly tied to MVP phase boundaries.

## Documentation discipline

- Update `docs/PHASE_STATUS.md` after each completed phase.
- Keep setup docs honest to what is actually implemented.
- Record known limitations instead of implying unfinished features exist.
